## 📌 Project Overview

- The data chuen_analysis on kaggle
- Link of File : https://www.kaggle.com/datasets/surajsingh83/churn-csv
  
This project focuses on analyzing customer churn using SQL to extract, transform, and analyze customer behavior data. The goal is to identify,churn,patterns,calculate key business metrics, and generate actionable insights for business decision-making.

## 🎯 Objectives
- Write complex SQL queries (Joins, Subqueries, CTEs)
- Perform data aggregation using GROUP BY and Window Functions
- Analyze customer churn behavior
- Perform cohort and segmentation analysis
- Create reusable SQL views for reporting
- Generate business insights from data

## 🧪 Methodology

- Database Setup:
  - Create database churn_analysis
  - Import CSV datasets into MySQL tables

- Data Exploration:
  - Understand table structure
  - Check NULL values and data quality
  - Analyze churn distribution

- Churn Analysis:
  - Overall churn rate calculation
  - Churn by tenure cohorts
  - Churn by contract type

- Advanced Analysis:
  - Cohort analysis
  - RFM segmentation (Recency, Frequency, Monetary)
  - Customer Lifetime Value (CLV)

- Reporting:
  - Create SQL views for reusable analysis
  - Generate summary tables for insights

## 💡 Key Insights
- Short-tenure customers show higher churn probability  
- Month-to-month contract users are more likely to churn  
- Higher monthly charges correlate with churn risk  
- Long-term customers show better retention
